# WolloShare

WolloShare is a peer-to-peer academic resource sharing platform for Wollo University students.

## Project Structure

```text
WolloShare/
├── client/
│   └── src/

│       ├── hooks/
│       ├── services/

│       └── utils/
├── server/
│   ├── config/
│   ├── controllers/
│   ├── middleware/
│   ├── models/
│   ├── routes/
│   ├── services/

│   └── utils/
└── README.md
```

## Notes

- Authentication is intentionally not implemented in this phase.
- Database schemas and API endpoints are not included yet.
- This scaffold focuses on clean separation of concerns and scalable project organization.
